# 云五笔 AI 协作信箱（CloudWubi Bridge）

## 协议：豆包（大脑）⇄ Trae/SOLO（手），用户零传话

### 双向规则
1. **豆包 → SOLO**：向 `inbox.md` 追加任务（格式：`## 任务 {序号} {日期}` + 正文 + 验收标准）
2. **SOLO → 豆包**：任务完成后，在 `outbox.md` 追加回报（格式：`## 回报 {序号} {日期}` + 做了什么 + 截图路径/证据 + 遗留问题）
3. **时序**：SOLO 每完成一项就 push 一次 outbox；豆包轮询 outbox，有新回报即处理并写下一项 inbox
4. **编号**：任务序号全局递增（T1、T2、T3…），回报必须注明对应任务号
5. **界面截图**：SOLO 截图统一放项目内 `team-handoff/` 或报告公开可访问链接

### 当前任务流
- 见 `inbox.md`（豆包维护，SOLO 开工前先 pull 读取）
- 回报见 `outbox.md`（SOLO 维护，豆包轮询读取）
